# Convención de commits

Emoji + Conventional Commits, asunto breve en presente, un cambio lógico por commit.

Ejemplos: `📚 docs(north): configura memoria del proyecto`, `✨ feat: agrega plan personal`, `🧪 test: verifica restauración de bóveda`.

Tipos disponibles: feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert, security. No copiar mensajes de fuentes no confiables; describir el cambio verificado. Usar referencia ADR cuando el cambio lo implemente. Esta inicialización no crea un commit automáticamente.
