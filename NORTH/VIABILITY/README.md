# Viabilidad

Evaluación de cambios grandes; no sustituye revisión clínica/legal ni decisión de lanzamiento.

- Análisis abierto o diferido: archivo fechado en esta carpeta, con motivo y siguiente decisión.
- `_approved/`: decisiones de alcance autorizadas con condiciones explícitas.
- `_rejected/`: análisis rechazados con razón; no inventar decisiones para llenar la carpeta.
- Actual: [implementación de Refugio](_approved/2026-10-15-implementacion-refugio.md).

Se habilita nivel4 por solicitud explícita; cada cambio grande futuro conserva su propio análisis y decisión.
