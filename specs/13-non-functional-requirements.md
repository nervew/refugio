# 13. Requisitos no funcionales

Estado: especificación para implementación; los objetivos siguientes **no son resultados medidos**. Prioridad P0 bloquea liberación; P1 debe completarse en el MVP salvo excepción registrada con responsable y fecha. La base técnica es React + TypeScript + Vite, PWA local-first con IndexedDB/Dexie y bóveda cifrada. Fuentes y límites de investigación: [hallazgos y fuentes](research/00-sources-and-findings.md) y [evidencia técnica](research/architecture-evidence.md).

## Supuestos y límites de disponibilidad

- Los objetivos de velocidad aplican al dispositivo de referencia registrado por QA, incluyendo modelo, SO, navegador, nivel de batería y versión de build; su selección ocurre antes de medir. No se declara cumplimiento hasta obtener resultados.
- La disponibilidad offline comienza tras descarga íntegra y verificación del contenido de esa versión. El sistema operativo puede desalojar almacenamiento o detener la PWA; el producto explica cómo conservar una exportación cifrada sin prometer recuperación.
- Sin conexión de datos pueden funcionar acciones `tel:` si el dispositivo tiene servicio telefónico y la persona confirma en el sistema. Una aplicación web no garantiza cobertura ni respuesta de un contacto.
- Cifrado en reposo reduce exposición local; no protege frente a dispositivo comprometido, XSS durante sesión abierta, capturas o acceso físico a pantalla desbloqueada. El navegador no permite prometer eliminación física de memoria ni borrado forense.
- WCAG, privacidad y revisión clínica son obligaciones de diseño y comprobación pendientes, no certificaciones ya obtenidas. No se afirma cumplimiento legal por usar cifrado.
